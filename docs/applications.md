# 実生活での応用イメージ

「量子コンピュータは結局何の役に立つのか」を、このリポジトリで実際に動かしたアルゴリズムの型ごとに
整理します。**現時点の小規模シミュレータ実験がそのまま実用化されているわけではありません**が、
どの分野で研究・実証実験が進んでいるかの見取り図として使ってください。

## 早見表

| アルゴリズムの型 | 得意なこと | 現実の応用領域（研究・実証段階を含む） | このリポジトリの対応例 |
|---|---|---|---|
| 量子乱数生成（QRNG） | 物理法則に基づく「真の」乱数生成 | 暗号鍵生成、公正な抽選・ガチャ、モンテカルロ・シミュレーション、乱数監査 | [例6](../examples/06_quantum_random_number_generator.md) |
| Grover探索 | 未整列データからの高速探索（理論上 $\sqrt{N}$ 倍） | データベース検索、SAT/制約充足問題、暗号解析（対称鍵の鍵長設計にも影響） | [例3](../examples/03_grover_search.md), [例10](../examples/10_grover_key_search.md) |
| QAOA（組合せ最適化） | 「〇〇の組み合わせの中から最良を選ぶ」問題 | 物流の配送ルート、金融ポートフォリオ、経理の消込・按分、シフト/リソース割当、通信の周波数割当、AIモデル学習の特徴量選択 | [例4](../examples/04_qaoa_maxcut.md), [例7](../examples/07_qaoa_budget_matching.md), [例8](../examples/08_qaoa_portfolio_jp_us.md), [例9](../examples/09_qaoa_feature_selection.md) |
| VQE（基底エネルギー探索） | 系の最も安定な状態（エネルギー最小）を求める | 分子・材料のシミュレーション（創薬、触媒設計、電池材料）、物性物理 | [例5](../examples/05_vqe_transverse_ising.md) |
| 量子鍵配送（QKD, 例: BB84） | 盗聴を物理法則で統計的に検知できる鍵交換 | 高セキュリティ通信（政府・金融機関の専用回線）、将来の耐量子通信インフラ | [例11](../examples/11_bb84_quantum_key_distribution.md) |

## それぞれもう少し具体的に

### 量子乱数生成 → 「公正さを証明できる」抽選・暗号

[例6](../examples/06_quantum_random_number_generator.md)のように `h` ゲートだけの回路で作った
乱数は、量子力学的に予測不可能です。さらに blueqat MCP はすべての実行に `run_id` を発行し
`verify_run` で後から検証できるため、「本当にその回路がその時刻に実行された」ことを第三者が
監査できます。宝くじの当選番号やガチャの排出、乱数監査が要求される場面（金融のリスクシミュレーション、
セキュリティ用途の鍵生成）と相性が良い特性です。

### Grover探索 → 「力ずくで探す」問題の高速化

構造化されていないデータの中から条件に合うものを探す問題（例: パスワード探索、SATソルバー、
巨大なリスト内の該当項目検索）は、古典コンピュータだと平均で $N/2$ 回の確認が必要ですが、
Groverアルゴリズムは理論上 $\sqrt{N}$ 回程度に減らせます。[例3](../examples/03_grover_search.md)は
最小の $N=4$ のケースですが、量子ビット数が増えるほど効果が理論上大きくなります
（ただし現実のハードウェアではノイズやゲート数の制約が支配的で、まだ実用上の優位性は限定的です）。
[例10](../examples/10_grover_key_search.md)ではこれを「トイ暗号の鍵探索」という形で拡張し、対称鍵
暗号の鍵長を量子コンピュータへの耐性の観点で（NISQの実用化がまだ先でも）今から2倍にしておく、
というPQC（耐量子暗号）分野の考え方につなげています。**ただし実在の暗号を攻撃したものではなく、
現在のハードウェアでAES等を攻撃することは規模的に不可能です**（例10の免責事項を参照）。

### QAOA → 「限られたリソースの最適な配分」問題

現実の多くの意思決定は「0か1かの組み合わせの中から一番良いものを選ぶ」という形（QUBO）に
落とし込めます。

- **物流**: どのトラックにどの荷物を積むか、どのルートを通るか
- **金融**: 予算内でどの投資案件の組み合わせを選ぶか（[例7](../examples/07_qaoa_budget_matching.md)の
  「予算ぴったり一致」は、経理での入金消込・在庫の詰め合わせにも同じ定式化が使えます）。
  [例8](../examples/08_qaoa_portfolio_jp_us.md)では実際の日米株データでMarkowitz型のポートフォリオ
  選択QUBOを組み、リスク許容度によって選ばれる銘柄の組み合わせがどう変わるかを検証しています
  （投資助言ではなく、計算フレームワークのデモです）
- **通信・スケジューリング**: 電波干渉を避ける周波数割当、会議室やシフトの重複回避
  （[例4](../examples/04_qaoa_maxcut.md)のMaxCutは「対立するペアを別グループに分ける」問題全般の
  雛形で、グラフ彩色やチーム分けにも応用できます）
- **AIモデル学習の前処理**: 候補となる特徴量の中から「予測に効いて、かつ互いに冗長でない」組み合わせを
  選ぶ特徴量選択も同じQUBOの形に落とし込めます。[例9](../examples/09_qaoa_feature_selection.md)では
  乳がん診断データセットでmRMR型の特徴量選択QUBOを組み、SelectKBestなど古典的な特徴量選択とテスト
  精度を正面から比較しています。

QAOAはこうした問題をパラメータ付き量子回路 + 古典最適化のハイブリッドで近似的に解きます。
NISQ（ノイズありの中規模量子デバイス）時代でも動かせるよう設計されている点が実用上のポイントです。

### VQE → 分子・材料の性質を計算する

化学反応や材料の性質は、電子の量子力学的な状態（ハミルトニアン）の基底エネルギーを計算することで
予測できますが、分子が大きくなると古典コンピュータでの厳密計算は指数関数的に困難になります。
VQEは量子コンピュータでこの基底エネルギーを近似的に求める代表的な手法で、創薬（薬剤候補分子の
結合エネルギー計算）・触媒設計・次世代電池材料の研究などで実証実験が進んでいます。
[例5](../examples/05_vqe_transverse_ising.md)はイジング模型という物理の教科書的な模型ですが、
`hamiltonian` に分子の電子構造から導いた項を渡せば同じ仕組みで分子計算に転用できます
（ただしその変換自体には別途、量子化学のライブラリが必要です）。

### 量子鍵配送（QKD） → 「盗聴が検知できる」通信

QAOA/VQE/Groverが「速さ」を売りにするのに対し、量子鍵配送（BB84など）の価値は速さではなく
**盗聴が物理法則によって統計的に検知できる**という質的な性質にあります（量子乱数生成と同じ
「速度ではない優位性」の系統です）。[例11](../examples/11_bb84_quantum_key_distribution.md)では
盗聴者がいる場合といない場合でBobの受信誤り率が理論通りに変わることをシミュレーションで確認して
います。**これはあくまで数理的な性質のシミュレーションであり、実際に量子通信路を経由した鍵配送を
このMCP経由で行えるわけではありません**（例11の免責事項を参照）。実用化はすでに一部の高セキュリ
ティ用途（政府・金融機関の専用回線など）で進んでいますが、専用のハードウェアと物理的な量子通信路
が必要です。

## 誠実に書いておくべきこと

- 現状の量子コンピュータ（NISQ）は、ノイズや量子ビット数の制約から、上記の応用のほとんどが
  まだ「研究・実証実験・一部のニッチな優位性」の段階です。古典コンピュータを全面的に置き換える
  段階には達していません。
- このリポジトリの例はすべて **10量子ビット以下・シミュレータ** の規模で、実生活の問題をそのまま
  解いているわけではなく、「同じ定式化パターンが実世界の問題にどう対応するか」を示す最小例です。
