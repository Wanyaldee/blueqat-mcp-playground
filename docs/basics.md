# 量子コンピューティングの基礎

このリポジトリの例を読むのに必要な最小限の前提知識をまとめます。厳密な教科書的説明ではなく、
`run_circuit` の入出力を理解するための実用的なメモです。

## まず、言葉の意味

量子コンピュータの説明には聞き慣れない言葉がたくさん出てきます。数式なしで、ひとことずつ説明します。
以下の説明では、[Qni](https://qniapp.github.io/qni/) と同じく、量子ビットの状態を
「**円の大きさ（＝出やすさ）**」と「**針の向き**」で思い浮かべると分かりやすくなります。

| 言葉 | ひとことで言うと |
|---|---|
| 量子ビット | 量子コンピュータの「ビット」。普通のビットは 0 か 1 のどちらかですが、量子ビットは「0 になる可能性」と「1 になる可能性」を両方持てます。 |
| 重ね合わせ | 「0 になる可能性」と「1 になる可能性」を**両方持っている状態**。まだどちらとも決まっていません。 |
| 測定 | 量子ビットの値を読むこと。読んだ瞬間に 0 か 1 の**どちらか1つ**に決まり、重ね合わせは消えます。 |
| 確率 | 測ったときに 0（または 1）が出る割合。50% なら、100回測ると大体50回出ます。 |
| ショット（shots） | 同じ回路を何回くり返して測るか。1回の測定では 0 か 1 しか分からないので、何百回も測って割合を見ます。 |
| 振幅 | 確率の「もと」になる数。円の大きさにあたり、2乗すると確率になります。普通の確率と違って「向き」も持っています。 |
| 位相 | 振幅の「向き」。針の向きにあたります。向きだけを変えても、その場で測ったときの確率は変わりません。でも、次のゲートの結果を変えます。 |
| 干渉 | 振幅どうしが足し合わさるときの現象。**同じ向きなら強め合い、逆向きなら打ち消し合います**。水面の波で、山と山が重なると高くなり、山と谷が重なると消えるのと同じです。 |
| もつれ（エンタングルメント） | 2つ以上の量子ビットの結果が連動している関係。片方が 0 ならもう片方も必ず 0、のように振る舞います。 |
| ゲート | 量子ビットに対する1つの操作。普通のコンピュータの「足し算」「NOT」のような基本の命令にあたります。 |
| 量子回路 | ゲートを順番に並べた手順書。左から右へ実行します。 |
| 状態ベクトル | すべての組み合わせ（1量子ビットなら 0 と 1、2量子ビットなら 00, 01, 10, 11）の振幅を並べた一覧。 |
| シミュレータ / 実機 | シミュレータは普通のコンピュータで量子コンピュータの計算をまねたもの。実機は本物の量子コンピュータで、ノイズ（誤り）が混ざります。 |

「重ね合わせ」と「干渉」はよく混同されます。**重ね合わせは状態**（両方の可能性を持っていること）、
**干渉は現象**（振幅が足し合わさって強め合ったり打ち消し合ったりすること）です。

## アダマールゲート（H）は何をするのか

H（アダマール）ゲートの役割をひとことで言えば、**重ね合わせを作るゲート**です。

- 0 の量子ビットに H を掛けると、0 と 1 が同じ大きさで重なった状態になります。測ると 0 と 1 が半々で出ます。
- 1 の量子ビットに H を掛けても、0 と 1 が同じ大きさで重なります。ただし 1 の針だけが逆向きになります
  （確率はやはり半々）。

では「干渉」はどこで起きるのでしょうか。**すでに重ね合わせになっている量子ビットにもう一度 H を掛ける**と、
0 の振幅と 1 の振幅がそれぞれ「0 への寄与」と「1 への寄与」に分かれ、それが足し合わされます。
このとき干渉が起きます。

- **H → H**: 「1 への寄与」が逆向きどうしで打ち消し合い、「0 への寄与」が強め合います。
  結果は必ず 0 に戻ります（50% と 50% の重ね合わせから、確率 100% の 0 に戻る）。
- **H → Z → H**: 間の Z が 1 の針だけを逆向きにします。今度は「0 への寄与」が打ち消し合い、
  結果は必ず 1 になります。

つまり、**H 自体は「重ね合わせを作る（ほどく）」ゲート**で、干渉は「重ね合わせに H などを掛けたときに
振幅が足し合わされる」ことで起きる現象です。グローバー探索などの量子アルゴリズムは、この干渉を使って
正解の振幅を強め、不正解の振幅を打ち消すように回路を組んでいます。

## 量子ビット（qubit）と重ね合わせ

古典ビットは `0` か `1` のどちらかです。量子ビットは測定するまで `0` と `1` の**重ね合わせ**の状態を
取れます。例えば `h`（アダマール）ゲートを $|0\rangle$ に掛けると、測定したときに50%の確率で `0`、
50%の確率で `1` が出る状態になります。

$$
H|0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)
$$

```json
{"gates": [{"gate": "h", "qubits": [0]}], "shots": 256, "output": "counts"}
```

これを実行すると `counts` はおおよそ `{"0": 128, "1": 128}` に近い値になります（統計的なゆらぎあり）。
これが[例6: 量子乱数生成](../examples/06_quantum_random_number_generator.md)の原理そのものです。

## 測定と確率

回路の最後で `m` / `measure`（または `run_circuit` が自動的に行う測定）をすると、重ね合わせ状態は
`0` か `1` のどちらかに「収束」し、以後その量子ビットは古典ビットと同じように振る舞います。
どちらが出るかの確率は、状態ベクトルの各基底状態の**振幅の絶対値の2乗**で決まります
（`output: "statevector"` で見える `re`/`im` の複素数がその振幅です）。

$0.7071067811865475 = \frac{1}{\sqrt{2}}$ の振幅を持つ状態は、確率にすると $\left(\frac{1}{\sqrt{2}}\right)^2 = 0.5$、つまり50%です。
[例1: ベル状態](../examples/01_bell_state.md)の `statevector` 出力がまさにこれです。

## エンタングルメント（量子もつれ）

`cx`（CNOT）のような2量子ビットゲートを重ね合わせ状態と組み合わせると、2つの量子ビットの測定結果が
互いに独立ではなくなる「エンタングルメント」が作れます。[例1: ベル状態](../examples/01_bell_state.md)・
[例2: GHZ状態](../examples/02_ghz_state.md)で見た通り、`00`/`11`（あるいは`000`/`111`）しか出ず、
`01`/`10` は一度も出ません。片方を測定した瞬間、もう片方の結果も確定します。

## ゲートの基本カテゴリ

- **1量子ビットゲート**（`h`, `x`, `y`, `z`, `rx/ry/rz` など）: 1つの量子ビットの状態を回転させる
- **2量子ビットゲート**（`cx`, `cz`, `swap` など）: 量子ビット同士を絡めてエンタングルメントを作る
- **測定**（`m`/`measure`、または`output`指定）: 重ね合わせを古典ビットの結果に落とし込む

詳しい一覧は [docs/gates.md](gates.md) を参照してください。

## このリポジトリで使う3つのアルゴリズムの位置付け

| アルゴリズム | 何をするか | 対応するツール |
|---|---|---|
| Grover探索 | 未整列データからの高速探索。理論上は古典の $\sqrt{N}$ 倍高速 | `run_circuit`（自分でオラクルを組む） |
| QAOA | 組み合わせ最適化（QUBO）の近似解法 | `run_qaoa` |
| VQE | ハミルトニアンの基底エネルギー（安定状態）を近似的に求める | `run_vqe` |

QAOAとVQEはどちらも「パラメータ付きの量子回路 + 古典最適化」を組み合わせるハイブリッド手法で、
現在のノイズの多い量子デバイス（NISQ）でも動かせるように設計されています。

表に出てくる言葉の意味です。

| 言葉 | ひとことで言うと |
|---|---|
| QUBO | 0/1 で答える「はい・いいえ」の選択を組み合わせて、点数（コスト）が一番低い組み合わせを探す問題の書き方。「この2つを同時に選ぶと減点」のようなルールを点数として書きます。 |
| 罰点（ペナルティ） | 守ってほしいルールを破ったときに足す点数。「ちょうど2人選ぶ」なら、2人でないときに点数を上げます。 |
| ハミルトニアン | 状態ごとの「エネルギー」を決める式。QUBO の点数表を物理の言葉で書き直したものと考えて構いません。 |
| 基底エネルギー | 一番低いエネルギー。最適化問題では「一番良い答え」の点数にあたります。 |
| 量子アニーリング | 答えが分かっている簡単な状態から、解きたい問題へ**ゆっくり**切り替えていき、一番低いエネルギーの状態に落ち着かせる方法。ゆっくりすぎると時間がかかり、速すぎると最適でない答えに落ちます。 |
| QAOA | 量子アニーリングの「ゆっくり切り替える」を、ゲートを数段重ねた回路でまねる方法。段数が少ないと最適解を外すことがあります。 |
| VQE | 回路でエネルギーを測り、普通のコンピュータが回路のつまみ（パラメータ）を直す、をくり返して一番低いエネルギーを探す方法。分子の計算に使われます。 |
| パラメータ（つまみ） | 回路の中の回転ゲートの角度。ラジオのつまみのように回して、作る状態を少しずつ変えます。 |
| アンザッツ（試しの回路の形） | つまみ付きの回路の「形」。この形が答えの状態を作れないと、どれだけつまみを回しても届きません。 |
| 期待値 | 何回も測ったときの平均。エネルギーは何回も測った平均で決めます。 |
| 変分原理 | どんな状態のエネルギーを測っても、本当の一番低いエネルギーより下にはなりません。だから下がれば下がるほど本当の答えに近いと言えます。 |
| 勾配（坂の向き） | つまみを少し回したとき、エネルギーが上がるか下がるか。VQE はこれを見て下る向きにつまみを回します。 |
| 局所解（くぼみ） | まわりのどこよりも低いのに、一番低い所ではない場所。ここに入ると最適化が止まります。 |
| HF（平均場近似） | 電子1つ1つが「ほかの電子の平均的な影響」だけを感じると考える近似。電子どうしがよけ合う効果を取りこぼすので、本当の値より少し高くなります。 |
| 厳密解（FCI） | 近似をせず、すべての可能性を調べて求めた本当の答え。小さな分子なら普通のコンピュータで計算できるので、VQE の答え合わせに使います。 |
| NISQ | 今の「ノイズが多く、量子ビットも多くない」量子コンピュータのこと。 |
| ヒューリスティック | 必ず最適解が出るとは限らないが、多くの場合に良い答えを出す方法。QAOA や量子アニーリングはこれにあたります。 |

## bit_order で混乱しないために

`run_circuit` の `counts`/`amplitude` は「文字列の先頭 = 量子ビット0」ですが、`statevector` の
インデックスは**リトルエンディアン**（インデックス`i`のビット`k`が量子ビット`k`）です。
2つの表現を見比べるときは、この並び順の違いに注意してください（詳細は
[docs/gates.md](gates.md#全ビットの-bit_order-について)）。

## 実用面での注意（誇張しないために）

- ここで使っているのはすべて**シミュレータ**上での実行です（実機QPUではありません）。
- 量子ビット数10・ショット数256程度の規模なので、古典コンピュータでも当然すぐ解ける規模の問題です。
  ここでの目的は「アルゴリズムの正しさをMCP経由で手軽に確認すること」であり、「量子優位性を実証すること」
  ではありません。
- 実生活での応用のイメージは [docs/applications.md](applications.md) にまとめています。
